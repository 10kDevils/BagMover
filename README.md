# BagMover

Drag your bag windows anywhere on the screen. Positions are remembered.

## Install

1. Open the [latest release](../../releases/latest) and download `BagMover-<version>.zip`.
2. Extract it into your `Interface/AddOns/` folder so you end up with `AddOns/BagMover/BagMover.toc`.

**WowUp**: *Get Addons → Install from URL* and paste this repository's address.

## Use

Click and drag any bag window by its background or title.

- `/bagmover reset` (or `/bm reset`): forget all saved positions
- `/bagmover lock`: lock or unlock dragging
